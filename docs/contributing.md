# Contributing to PolyGen

## Development Setup
1. Clone the repository and enter the workspace.
2. Install Python dependencies: `pip install -r backend/requirements.txt`.
3. Install frontend dependencies: `cd frontend && npm install`.

## Code Quality Standards
- Format Python code with PEP8 and Black guidelines.
- Ensure all pytest tests pass before committing: `python -m pytest -v`.
- Build the frontend bundle cleanly: `npm run build`.
- Write descriptive Conventional Commit messages (`feat:`, `fix:`, `docs:`, `test:`).
