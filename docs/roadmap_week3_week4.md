# PolyGen Roadmap: Weeks 3 & 4

## Week 3: Texture Generation & Mesh Optimization
- **Stable Diffusion Texturing:** Generate diffuse and normal maps using depth maps/ControlNet.
- **Trimesh UV Unwrapping:** Implement automatic UV parametrization on `.obj` meshes.
- **QEM Decimation:** Apply Quadric Error Metrics decimation to reduce polygon count to game-ready 10k triangles.

## Week 4: Export Pipeline & Visual Polish
- **GLTF/GLB Exporter:** Pack geometries, PBR materials, and textures into binary `.glb` containers.
- **HDRI Environment Maps:** Add realistic IBL (Image-Based Lighting) in Three.js viewport.
- **Engine Preset Exporters:** One-click presets optimized for Unreal Engine 5 and Unity 6.
